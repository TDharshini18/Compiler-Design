PROCEDURE:
1. Create the FLEX file optimize.l to tokenize identifiers, numbers, and the operators + - * / = ;.
2. Create the BISON file optimize.y with a grammar for assignment statements and expressions.
3. In the semantic actions for each expr rule, check whether constant folding, strength reduction, or algebraic
simplification applies, and print a comment indicating which optimization fired.
4. Compile using:
    o flex optimize.l
    o bison -d optimize.y
    o gcc lex.yy.c optimize.tab.c -o optimize -lfl
5. Run ./optimize and enter three-address-code-style statements ending with &#39;;&#39;, terminate input with Ctrl+D.
6. Verify that constants are folded, x*1 / x/1 / x+0 / x-0 are simplified, and x*2 is converted to x+x.
7. Test with multiple statements to confirm all three optimization types are triggered correctly.
